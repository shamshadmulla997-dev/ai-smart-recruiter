# 🚀 AI Smart Recruiter & Career Guide

A full-stack web application that uses AI-powered skill matching to connect candidates with their ideal job roles and provide personalized career guidance.

## 🌟 Features

- 📄 **PDF + Text Resume Upload** — Parse resumes with Apache PDFBox
- 🎯 **AI Job Role Matching** — Match candidates to 10+ predefined roles
- 📊 **Skill Gap Analysis** — Identify missing skills with YouTube learning links
- 🗂️ **Resume Dashboard** — View all candidates in beautiful cards
- 🧭 **Career Guide** — Per-candidate skill analysis and top matching roles
- 🏆 **Leaderboard** — Rank candidates by match score with 🥇🥈🥉 medals
- 📈 **Analytics Dashboard** — Charts showing top skills and popular roles
- 🤖 **AI Chatbot** — Career guidance assistant with rule-based responses
- 📑 **PDF Report Export** — Download candidate career reports
- 🔐 **Login System** — Spring Security with BCrypt password hashing
- 🎨 **Modern Dark UI** — Responsive design with gradients and animations
